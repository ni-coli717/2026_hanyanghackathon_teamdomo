# 코넥트 시연 웹

부스 시연용. 실제 앱 화면(`components/odor_map`)을 그대로 띄우고, 2026-08-19 저녁의 실제 기록을 시간 순서대로 다시 돌린다.
앱 코드는 고치지 않는다. 앱을 고치면 시연 화면도 같이 바뀐다.

## 실행
저장소 루트의 `run_demo_web.bat` 더블클릭 → Chrome/Edge 에서 http://localhost:8765/demo/
구역·단계·기록은 인터넷 없이 나온다. 지도 바탕 그림과 글꼴은 `sw.js` 가 저장해 둔 것을 쓴다.
1366×768 노트북에서는 전체 화면(F11)이 아니어도(보이는 높이 657px) 다 들어간다.

### 발표 전 (인터넷 없는 부스 대비)
1. 시연할 노트북·브라우저에서, 인터넷이 있을 때 시연을 처음부터 끝까지 한 번 돌린다(리허설).
   그때 본 지도 조각과 글꼴만 이 브라우저에 저장된다(미리 대량으로 받지 않음: OSM 타일 사용 정책).
2. 부스에서 S 를 눌러 "지도 저장됨 N장 · 인터넷 …"을 확인한다. 20장 이상이면 지도 바탕이 나온다.
3. 저장본도 인터넷도 없으면 지도 바탕 없이 구역 면만 보인다('지도 연결 실패' 문구는 뜨지 않음).

## 조작
맥박 치는 곳을 누르면 다음으로 넘어간다.
시간 막대 → [모델 판단 과정 보기] → [공기청정기 일정] → [20:20으로] → [주민 기록] → ＋기록 → 나요 → 심함 → [외부 센서 측정값 확인] → [다시 학습] → [처음부터]
예비 키: → / PageDown 다음 · ← / PageUp 이전 · 1–6 장면 바로 가기 · S 설정(USB 연결, 센서 연습 신호, 속도, 지도 저장 상태, 처음부터)

### 발표자 안내 (예전 설정 창 아래 목록)
- 카드의 단추나 맥박 치는 곳을 누르면 진행. 장면 안의 움직임만 저절로 흐르고, 다음 장면은 누를 때만 넘어감.
- 센서 장면 전에 센서 USB 연결 또는 연습 신호를 켜 두기(연결 전에는 그래프 자리에 '센서 연결 전'만 보임).
- 시계가 흐르는 동안(장면 3·4)은 카드가 사라지고 지도 가운데에 큰 시계가 뜬다. 끝나면 위쪽 띠 시계로 돌아감.
- 시연 화면에서는 앱의 탭 중 예보 · ＋기록 · 기기만 보인다(지금 · 참여 · 안내, 정기 관측 칩, 일부 지도 단추와 작은 설명은 `demo.js` 가 앱 화면 안에 넣는 CSS 로 숨김. 앱 코드는 그대로).

## 장면
1. 기상 예보(15:00): 예보 탭의 시간 막대가 15시부터 21시까지 움직인다. 19시까지 낮음 → 20시 보통 → 21시 높음.
2. 모델 판단: 15·20·21시의 바람 → 요인별 기여도 → 점수 → 단계.
3. 공기청정기 예약: 시간선이 먼저 뜨고 카드가 시간선을 가리킨다. [20:20으로]를 누르면 큰 시계가 흐르고 20:20 에 가동(시간선 팬이 돌고, 앱 기기 카드가 청록으로 바뀜).
4. 주민 기록(21:46): 큰 시계가 흐르며 다른 주민 기록이 들어오는 순간 구역 이름표의 숫자가 강조된다. 발표자가 실제 ＋기록 화면으로 기록한다.
5. 센서 측정(21:51): USB 센서 값 또는 '연습용 가상 신호'.
6. 다시 학습(22:40): 순환 4단계(03 에 AUC), 실제 앱 QR.

## 자료
`python -m demo.build_data` 가 `demo/data.js` 를 만든다. 지어낸 값 없음.
- 기상: AWS 441(모델을 학습한 관측소) 그날 관측값을 '그날의 예보'로 넣음. 모델 관측소와 다르면 빌드가 멈춘다.
- 단계·점수: 앱과 같은 `predict_windows()`(실제 제보로 학습한 모델)
- 기기 일정: 앱과 같은 `odor_model.prerun.plan()`(미리 켜기 40분, '높음' 기준)
- 주민 기록: `data/private/reports.csv` 에서 그날 15시 이후 '냄새 남' 제보의 시각·구역·강도만 읽는다. 참여자 코드·장소 글·좌표는 data.js 에 넣지 않는다.
- 발표자가 ＋기록으로 대신하는 제보: 우리 집 구역(운양역)의 '높음' 시간대 제보(21:46, 강도 3)
- 시연 속 주민 위치: 운양역 구역 면 안에서 경계와 가장 먼 점(지어낸 좌표, 실제 참여자 위치 아님)
- AUC·사건 수: `odor_model/artifacts/evaluation_cc_441.md` 에서 읽음
- QR: `qr.svg`(https://odor-compass.streamlit.app), segno 로 한 번 만든 정적 파일

## 시연에서만 바꿔 끼우는 것 (`shim.js`)
시계(2026-08-19) · 내 위치 · 기기 서버 응답 · 브라우저 저장소. 기록은 DB에 저장하지 않는다.

## USB
- 센서 판: 기준 = 처음 5초 평균(점선). 포트가 끊기거나 5초 넘게 값이 없으면 '센서 끊김'으로 바뀌고, 마지막 값은 보여 주지 않는다.
- 센서: 줄마다 `{"adc_mq137":812}` 같은 JSON, `adc_mq137=812`, 또는 숫자 하나. 115200 baud.
  지금 센서 노드 펌웨어는 측정값을 시리얼로 내보내지 않는다 → `proposals/node_serial.diff`(1초마다 adc_mq137 한 줄).
- 공기청정기: 가동 구간에 들어가면 `FAN ON`, 나오면 `FAN OFF`. 포트를 열 때 DTR/RTS 를 내리고 3초 뒤 한 번 더 보낸다(ESP32 재부팅 대비).
  펌웨어가 받으려면 → `proposals/purifier_usb.diff`.
